# QvPalette

> **ベータ版です。** 仕様や保存形式が、予告なく変わることがあります。VCC の設定で「プレリリース版を表示」を入れると、選べます。

QvPen（v3.3.15）に追従する、インクパレット拡張です。QvPen 本体は**一切改変しません**。
ペン 1 本で、最大 4096 種類の色・マテリアルと、1024 段階の太さを切り替えられ、全員に同期されます。

## 特長

- **ペン 1 本で全色・全太さ**: ペンの本数は、同時に描ける人数や、手元に置ける色の枠数を意味します。
- **絵の具パレット型の召喚・配置具**: ペンスタンドの横のパレット型のオブジェクトを掴んで好きな場所に置くと、その上にパネルが開きます。
- **VR / Desktop 対応**: VR ではペン先と人差し指で触れて操作、Desktop ではマウスのクリックとドラッグで操作できます。
- **太さのスライダーとプリセット**: スライドに加えて、3.0 / 5.0 / 10.0 / 30.0 mm（2 ページ目は 50 / 80 / 100 / 150 mm）のプリセットがあります。
- **お気に入り 8 枠**: 色と太さをセットで登録できます。ワールドごとに、個人の設定として保存されます。
- **後から入室した人にも反映**: 台帳方式（色や太さを切り替えた点だけを記録）で同期します。
- **パレットエディタ**: インクごとにマテリアルとグラデーションを設定でき、ゲーム内に近いプレビュー（20 cm の線、太さの調整、PC/Quest の切り替え）をその場で確認できます。

## 導入方法（VCC）

1. VCC の「Settings → Packages → Add Repository」に、配布元の VPM リスト URL を登録します。 **[URL は公開時に記載]**
2. プロジェクトの「Manage Project」で、**QvPalette** の「+」を押します。QvInkPreview も一緒に導入されます。
3. シーンを開き、メニューの **`Tools > Yakigura > QvPalette > Setup（このシーンに導入・更新）`** を実行して、シーンを保存します。
4. シーン内の `QvPen_PenManager` が自動で検出され、台帳とパネルが生成されます。

## 使い方

- **ペンの本数を変えたとき**: もう一度 `Scan Scene & Rebind` を実行します。
- **インクの設定**: `Tools > Yakigura > QvPalette > Palette Editor` を開き、インクごとのグラデーション、マテリアル（PC / Quest）、縁取りを設定します。ウィンドウ上部の「プレビュー」で見た目を確認できます。
- **台帳の容量**: シーンの `QvPalette/Setup` オブジェクトのインスペクターで、チャンク数と容量を調整します（既定は、ペン 1 本あたり 4,096 回で、十分な容量です）。

## 削除方法

シーン上の `QvPalette` の GameObject を削除し、パッケージをプロジェクトから外します。QvPen 側には、何も残りません。

## 既知の制限

1. **QvPen のバージョン**: 3.3.15 で検証しています。将来のバージョンで色の同期の仕様が変わると、動作確認が必要です。
2. **旧版との併用禁止**: 過去の試作版（`QvPalet`、`QvPenInkPalette`、`TakadaQvPenInkPalette`）と、同じシーンに置かないでください。
3. **初期スタイル**: 起動時に、全ペンの初期スタイルが、パレットの 0 番に統一されます。
4. **描画中のプレビュー**: 描いている最中の線は、本人にしか見えません（QvPen の仕様です）。
5. **消しゴムの判定**: 当たり判定を作り直さない設定のため、初期の太さと変更後の太さの差の分だけ、わずかにずれます。
6. **お気に入り**: VRChat の Persistence を使うので、ワールドごとの保存です。他のワールドには、持ち出せません。
7. **パネルの枚数**: 生成されるパネルは 2 枚（右手用、左手用）で、ペンの本数を増やしても増えません。Desktop では右手用だけを使います。
